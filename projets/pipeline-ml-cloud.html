Contexte

Prédire le prix de vente d'une maison à partir de 12 caractéristiques (surface, chambres, salles de bain, étages, équipements, ameublement), avec un pipeline qui reste entièrement dans Snowflake.

Démarche

  • Ingestion : stage externe vers le bucket S3, table typée, COPY INTO depuis du JSON.
  • Exploration : statistiques, valeurs nulles, prix par équipement, matrice de corrélation.
  • Feature engineering : encodage binaire et ordinal, normalisation pour les modèles linéaires, split 80 / 20 reproductible.
  • Comparaison de 4 modèles (régression linéaire, Ridge, Random Forest, XGBoost) sur MAE, RMSE et R².
  • Optimisation : GridSearchCV sur XGBoost, RandomizedSearchCV sur Random Forest, validation croisée à 3 plis.
  • Enregistrement dans le Model Registry, inférence depuis le registry, prédictions sauvegardées en table, application Streamlit.
